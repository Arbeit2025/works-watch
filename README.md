# Works見守りボード（works-watch）

公開中の自作作品サイト（16件）の死活（HTTPステータス）と応答時間を、
まとめてチェックして表で見せる単一ファイル Flask の Web ツールです。
DB は使いません。監視対象は app.py 内の固定リストです。

## できること

- トップページに対象一覧（名前＋URLリンク）と「チェック実行」ボタンを表示
- チェック実行で全対象を並行取得し、状態（OK／異常／到達不可）・HTTPコード・
  応答時間（ミリ秒）・チェック時刻（JST）を結果表に表示
- 1件あたりのタイムアウトは30秒

## 使い方（ローカル起動）

```bash
pip install -r requirements.txt
python app.py
```

ブラウザで http://127.0.0.1:5000/ を開き、「チェック実行」を押してください。

## Render へデプロイ

render.yaml が同梱されています。Render でこのリポジトリから新規 Web Service を
作ると、Free プランで `gunicorn app:app` が起動し、ヘルスチェックは /healthz です。

## 注意（Render Free プランのスリープについて）

監視対象の多くは Render Free プランで動いており、無通信時にスリープします。
スリープ中のサイトは初回応答が遅くなったり、一時的に「到達不可」と表示されたり
することがありますが、それだけで障害とは限りません。少し待ってから対象サイトを
開き直すと起動して表示される場合があります。

## テスト

```bash
python -m unittest discover -s tests
```

HTTP取得はモックしているため、実ネットワークには出ません。
